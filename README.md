A robot's two-line confession: one sentence owning a specific mistake, one naming the lesson and the fix.

> I'm sorry I watered the plastic fern every morning for a month while the real fern by the window dried out.
> I have learned to check the soil before I follow the schedule, so from now on I touch the dirt first and water only what is actually thirsty.

## How it works

`main.py` (Python 3 standard library only) writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
